MCP Integration
Connect your AI agent to Ragna Analytics via Model Context Protocol. Auto-discover tools, pay per request.
🔌

Auto-Discovery

AI agents automatically discover all 13 tools when connected. No manual configuration needed.

💳

x402 Payments

Each tool has its own price. Agents pay USDC on Base automatically when calling paid tools.

🔗

SSE Transport

Connect via Server-Sent Events. Compatible with Claude, Cursor, and any MCP client.

⚡

Real-Time Data

All tools return live on-chain data. No caching, no stale data.

Connect with Claude Desktop
{
  "mcpServers": {
    "ragna-analytics": {
      "url": "https://x402-mcp.onrender.com/sse"
    }
  }
}
Connect with JavaScript
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { SSEClientTransport } from "@modelcontextprotocol/sdk/client/sse.js";

const client = new Client({ name: "my-agent", version: "1.0.0" });
const transport = new SSEClientTransport(new URL("https://x402-mcp.onrender.com/sse"));
await client.connect(transport);

// List available tools
const { tools } = await client.listTools();
console.log(tools.map(t => t.name));
// → ["get_portfolio", "get_tx_history", "get_defi_yields", ...]

How x402 Payments Work

  1. Your agent hits an endpoint without payment
  2. Server returns HTTP 402 + payment requirements
  3. Agent signs USDC payment with wallet
  4. Agent retries with payment signature
  5. Server verifies → returns data → USDC settled on-chain
