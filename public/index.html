How it works

1

Call any endpoint

Send a GET request to any of the 69 endpoints. No API key needed.

2

Pay with x402

Server returns 402. Your agent pays USDC on Base or Solana. Automatic.

3

Get the data

Structured JSON response. On-chain intelligence in milliseconds.
